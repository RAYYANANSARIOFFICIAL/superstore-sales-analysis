# Superstore Sales Analysis – Python

## Project Overview
This project analyzes Superstore sales data using Python to identify sales trends, profit patterns, customer behavior, and business insights.

## Dataset
- Total Records: 9,994
- Total Columns: 21

## Tools & Libraries
- Python 3.14
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Data Loading and Inspection
2. Data Cleaning and Date Conversion
3. Year-wise Sales and Profit Analysis
4. Region-wise Analysis
5. Category-wise Analysis
6. Monthly Sales Trend
7. Sub-Category Analysis
8. Customer Segment Analysis
9. Ship Mode Analysis
10. Top 10 Products and Customers
11. Discount Analysis
12. Correlation Analysis and Heatmap

## Key Findings
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Technology generated the highest category sales and profit.
- West region recorded the highest sales.
- Phones recorded the highest sub-category sales.
- Copiers generated the highest sub-category profit.
- November recorded the highest monthly sales.
- Tables recorded the highest sub-category loss.
- Discount and Profit correlation: -0.22.

## Project Files
- `Superstore_Analysis.ipynb` – Jupyter Notebook
- `Superstore_Analysis.py` – Python Script
- `requirements.txt` – Required libraries

## How to Run
Install the required libraries:

`py -3.14 -m pip install -r requirements.txt`

Keep the dataset CSV in the same folder as the Python files before running the analysis.

## Conclusion
This project demonstrates practical Python data analysis skills, including data inspection, aggregation, visualization, and business insight generation.
