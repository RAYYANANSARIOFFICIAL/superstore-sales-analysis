
# SQL - Superstore Sales Analysis

## Project Overview
This folder contains SQL queries used to analyze the Superstore Sales Dataset using MySQL 8.0.

## Dataset Information
- Total Records: 9,994
- Total Orders: 5,009
- Total Customers: 793
- Total Products: 1,862

## Tools Used
- MySQL 8.0
- MySQL Command Line Client

## SQL Concepts
- SELECT and DISTINCT
- COUNT and SUM
- GROUP BY and ORDER BY
- Aggregate Functions
- STR_TO_DATE
- LIMIT

## Analysis Performed
1. Data Exploration
2. Year-wise Sales and Profit
3. Region-wise Analysis
4. Category-wise Analysis
5. Sub-Category-wise Profit
6. Segment-wise Analysis
7. Ship Mode Analysis
8. Top 10 Products by Sales
9. Top 10 Products by Profit
10. Top 10 Customers by Sales and Profit

## Key Findings
- Technology generated the highest category sales.
- West was the highest-selling region.
- Consumer was the strongest customer segment.
- Standard Class generated the highest sales.
- Tables recorded the highest sub-category loss.
- Canon imageCLASS 2200 Advanced Copier generated the highest product sales and profit.
- Tamara Chand was the most profitable customer.
