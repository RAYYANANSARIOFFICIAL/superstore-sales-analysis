# Superstore Sales Analysis – Power BI Dashboard

## Overview
This Power BI dashboard provides an interactive analysis of Superstore sales, profit, orders, and customers.

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Sales Trend over Time
- Sales by Category
- Sales by Region
- Profit by Sub-Category
- Sales by Segment

## Interactive Filters
- Year
- Region

## Tools Used
- Microsoft Power BI Desktop

## Key Insights
- Technology generated the highest sales and profit.
- West region generated the highest sales and profit.
- Tables sub-category generated a significant loss.
- Consumer segment contributed the highest sales.

## File
- `Superstore_Sales_Dashboard.pbix` – Interactive Power BI dashboard.

## Purpose
This project demonstrates data visualization, interactive dashboard development, and business data analysis using Power BI.
