# Superstore Sales Analysis

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel. The objective is to identify sales trends, evaluate profitability, compare product categories and regions, and present business insights through an interactive dashboard.

## Dataset Information
- Dataset: Sample Superstore
- Records: 9,994
- Columns: 21
- Data Source: Kaggle
- Domain: Retail Sales

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Visualization

## Data Cleaning
The following steps were performed:
- Checked missing values.
- Checked duplicate records.
- Standardized Order Date and Ship Date formats.
- Corrected column names.
- Formatted Sales and Profit values.
- Formatted Quantity and Discount columns.
- Prepared the dataset for analysis.

## Analysis Performed
1. Overall Sales and Profit Analysis
2. Category-wise Sales and Profit Analysis
3. Region-wise Sales and Profit Analysis
4. Sub-category Profitability Analysis
5. Monthly Sales Trend Analysis (2014–2017)

## Key Business Insights
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Technology generated the highest category sales and profit.
- West region recorded the highest sales and profit.
- Tables sub-category recorded the highest loss.
- November 2017 recorded the highest monthly sales.

## Dashboard
An Excel dashboard was created to display:
- Total Sales KPI
- Total Profit KPI
- Monthly Sales Trend
- Category-wise Sales and Profit
- Region-wise Sales and Profit
